## Project Description

**Keyboard Psychologist™** is an intentionally useless web application built to over-analyze every single keystroke you make while typing. Instead of helping you build speed or accuracy, the application actively roasts your typing habits, confiscates keys if you panic-type, auto-corrects your text into passive-aggressive statements, and forces you to stare into a pair of judgemental eyes that follow your cursor around the screen.

---

## The Problem (That Didn't Exist)

Modern technology continuously measures your steps, heart rate, and sleep—yet completely ignores the emotional state of your fingers while typing! Software engineers have spent decades optimizing keyboards for speed, leaving a massive gap in **keystroke-based psychological evaluation**.

---

## The Solution (That Nobody Asked For)

We created an interactive web interface that:

* **Tracks Hesitations & Aggression:** Counts every spacebar hit as a "Hesitation" and every enter key as "Aggression."
* **Confiscates Keys:** Automatically files a legal restraining order and locks out keys if you slam them too many times in panic.
* **Judgemental Eye Tracker:** Continuously tracks mouse coordinates to keep eyes focused directly on you while you attempt to complete a short evaluation paragraph.
* **Self-Destructing Diagnosis:** Generates a custom psychological profile after typing, only to redact and self-destruct it 5 seconds later so you can never keep it.
* **Panic Button:** Instantly flips the DOM into high-contrast emergency color mode when the anxiety becomes overwhelming.

---

## Technical Stack & Architecture

* **Frontend:** HTML5, CSS3 (Flexbox/Grid layout)
* **Logic Engine:** Vanilla JavaScript (ES6+)
* **Audio Synthesis:** Web Audio API (real-time generated pitch-shifted keypress sounds and meow mode)
* **Event Management:** Event Listeners capturing `keydown` / `mousemove` and intercepting default browser scrolling behaviors via `e.preventDefault()`.

---

## How it Works (Workflow)

```
[ User Moves Mouse ] ---> Dynamic Eye pupil tracking via JS coordinates
         │
[ User Types Text ]  ---> Real-time event detection (Keys, Backspaces, Spaces)
         │           ---> Triggers pitch-shifted Web Audio API sound
         │           ---> Triggers Passive-Aggressive Auto-Correct engine
         │
[ Key Slamming ]     ---> Key Confiscation System triggers (Locks Key + Visual Heatmap update)
         │
[ Click Stop/Diagnose]---> Generates psychological roast profile
                          ---> 5-Second Self-Destruct Timer initiates

```

## Features & Highlights

1. **Judgemental Eye Tracker:** Real-time CSS/JS pupil tracking following the cursor.
2. **Key Confiscation System:** Automatically revokes and visual-crosses out keys on the onscreen virtual heatmap if pressed in panic.
3. **Passive-Aggressive Auto-Correct:** Automatically alters words in real time (e.g., swapping `sorry` to `sorry (not really)`).
4. **Self-Destructing Diagnosis:** Displays a 5-second countdown before redacting the user's evaluation results.
5. **Panic Button Mode:** Instantly toggles a flashing high-contrast CSS state to handle user typing burnout.
